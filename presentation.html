Motivation & Objectives

Why Stateful Filtering & Multi-Client Security?

  • Stateless Limitations: Traditional packet filters inspect packets in complete isolation, requiring wide-open inbound ports and failing against spoofed attacks.
  • Zero-Trust Architecture: Perimeter defenses must enforce granular policy by source IP, isolating internal administrative workstations from rogue or guest endpoints.
  • Application-Layer Threats: L3/L4 filters miss domain exfiltration; firewalls need Layer 7 domain filtering to block unauthorized search & malware sites.
  • Real-Time Deflection: Visualizing dropped packets, connection state, and return routing in real time.

Packet Evaluation

5-Tuple Structure & RFC Protocol Standards

  • The 5-Tuple Identity: Source IP, Destination IP, Source Port (ephemeral 49152-65535), Destination Port (service), Transport Protocol (TCP/UDP/ICMP).
  • RFC 791 (IPv4): 32-bit unsigned bitwise CIDR mask evaluation (e.g., 192.168.1.0/24 subnet calculations).
  • RFC 793 (TCP): Flag parsing (SYN, ACK, PSH, FIN, RST) verifying 3-way handshake compliance.
  • RFC 768 (UDP): Stateless flow mapping for DNS queries on Port 53.

Core Engine

Stateful Connection Tracking (conntrack)

  • Bidirectional Session Table: Maps forward hash srcIp:srcPort->dstIp:dstPort and reverse return key simultaneously.
  • State Lifecycle: Tracks transitions: NEW (SYN) → SYN_RECV → ESTABLISHED → FIN_WAIT → CLOSED.
  • Rule #1 Precedence: All established and related return packets immediately match Rule #1, bypassing redundant filtering.
  • Automatic Garbage Collection: Idle flows and torn-down FIN/RST connections clean up automatically.

Decision Logic

Priority Rule Engine & Deflection Mechanics

  • Strict First-Match Semantics: Rules evaluate sequentially (#1, #2, #3...); the first matching rule dictates ALLOW or DENY. Evaluation stops immediately.
  • Zero-Trust Default Deny: Any traffic not explicitly permitted by an enabled rule falls through to Rule #10 (Default Deny All).
  • Dynamic Curved Deflection: Blocked packets don't just disappear—they curve off the firewall shield along a quadratic Bézier SVG arc.
  • Live Rule Management: Add custom rules, toggle enable/disable, or drag-and-drop priority in real time!
